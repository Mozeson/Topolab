# ניווט קבוצתי (מולטיפלייר)

עד 4 משתתפים בחדר עם קוד של 4 ספרות.
- המנהל בונה מפה וציר. הציר מתחלק אקראית לקטעים רציפים, וכל אחד לומד ומוביל נקודה אחת או שתיים (גם הסיום הוא יעד).
- מי שמקבל את 2 ואת 3 מקבל את שתיהן. אף אחד לא מקבל נקודות מפוזרות.
- את הקטעים של האחרים לא רואים, ולכן הולכים אחרי המוביל.
- נקודה נחשבת רק כשכל הקבוצה לידה.

## איך משחקים

1. **פתיחת חדר:** "קבוצה" בסרגל העליון. מקלידים שם, יוצרים חדר ומשתפים את הקוד. חברים מצטרפים עם הקוד.
2. **המנהל מכין:** בונה מפה וציר כרגיל ("עריכת המפה והציר"), ובוחר:
   - המפה בשטח: רק הקטע שלי, או בלי מפה.
   - גמלים.
   - ג״ג עם רוחות.
3. **"שליחה וחלוקה":** כולם מקבלים את המפה של המנהל ואת התדריך שלהם.
   - בתדריך כל אחד רואה רק את הקטע שלו: נקודת המוצא שלו והנקודות שלו.
   - מוצג גם סדר ההובלה: מי מוביל אילו מספרים, בלי המיקומים.
4. **"מוכנים ✓":** כל אחד טוען את השטח. הקבוצה יוצאת יחד כשכולם מוכנים.
5. **בשטח:**
   - **המוביל:** שורה בראש המסך ("אתם מובילים · לנקודה 2" / "מוביל/ה: דנה · 40 מ׳ מכם").
   - **חברי הקבוצה:** דמויות בצבע שלהם עם שם.
   - **נקודה:** נחשבת כשכולם ברדיוס של 40 מ׳ ממנה. ההובלה עוברת לבא בתור.
   - **מי שמתרחק:** יותר מ־150 מ׳ מהמוביל מקבל ומציג אזהרה. אין חץ אליו: מוצאים אותו, או שהוא חוזר לקבוצה.
   - **📣 צעקה (Y):** כולם שומעים מאיזה צד ובאיזו עוצמה, ורואים את הכיוון והמרחק המשוערים.
   - **רחפן:** אין.
   - **עונשים:** גמלים ורוחות מוסיפים זמן לכל הקבוצה.
6. **סיום:** זמן קבוצתי אחד (שעון השרת, ועוד העונשים).
   - המנהל יכול לשלוח סיבוב נוסף מחלון הקבוצה.
   - אורח שיוצא מהחדר מקבל בחזרה את המפה שלו.

## מבנה

| קובץ | מה |
|---|---|
| `src/team.js` | לוגיקה טהורה, משותפת לדפדפן ולשרת: חלוקה רציפה (`splitCourse`), מה כל אחד רואה (`visibleIndices`), כולם בנקודה (`groupAt`), מי התרחק (`strays`), קוד חדר. בדיקות ב־`tests/team.test.js`. |
| `server/server.js` | שרת Node: מגיש את `dist/` (מטמון כמו קודם) ומנהל חדרים ב־WebSocket ב־`/ws`. שופט את המשחק: מחלק, מתחיל כשכולם מוכנים, בודק פעם ב־100 ms אם כל הקבוצה ביעד, מעביר את ההובלה, מדווח על מי שהתרחק, מעביר צעקות, סוכם עונשים ומודד את הזמן. החדרים בזיכרון (הפעלה מחדש של השרת מסיימת אותם). בדיקה: `tests/server.test.js` מריצה שרת אמיתי עם שני לקוחות. |
| `src/multiplayer.js` | הצד של הדפדפן: חלון "קבוצה" (יצירה, הצטרפות, לובי, אפשרויות המנהל) וחיבור ה־WebSocket. העברה למשחק: `navGame.openTeam` ו־`teamMessage`. |
| `src/nav-game.js` | מצב קבוצה (`team`): תדריך חלקי, המתנה לכולם, שליחת מיקום 10 פעמים בשנייה, נקודות שמגיעות מהשרת (`teamPunch`), דמויות חברים (`buildMate` / `updateMates`), שורת ההובלה, צעקה וחסימת הרחפן. |
| `src/scene.js` | `createTeam`: המפה נשלחת כ־project שמור (`serializeProject`). אצל אורח השמירה האוטומטית מושהית (`teamGuest`), והמפה שלו חוזרת ביציאה. |

**פרוטוקול (JSON):**
- **לקוח ← שרת:** `create`, `join{code}`, `leave`, `setup{project, points, extent, options}` (מנהל), `ready{pos}`, `pos{u,v,h}`, `shout`, `penalty{seconds,reason}`, `again` (מנהל).
- **שרת ← לקוח:** `joined`, `room`, `error{code,text}`, `setup{…, split}`, `start{leader}`, `pos{list}`, `next{next,leader}`, `strays{list}`, `shout{id,u,v}`, `penalty{total}`, `left`, `finish{elapsed,penalty,total}`.

## הרצה

- **ייצור (Railway):** ה־`Dockerfile` בונה את האתר ומריץ `node server/server.js` על `$PORT`. בשירות אחד: האתר והחדרים.
- **פיתוח:** `npm run server` (פורט 8787) לצד `npm run dev`. Vite מעביר את `/ws` לשרת.
- **בדיקה מקומית של גרסת הייצור:** `npm run build && PORT=8080 npm start`.
