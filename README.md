# מעבדת פני שטח (Topolab)

כלי לימודי לפיסול פני שטח ולקריאת מפות טופוגרפיות: מפסלים גובה במפה מלמעלה, רואים את התבליט בתלת־ממד,
וחושפים קווי גובה, תכסית, זרימת מים ותצפית מתוך השטח.

## הרצה

```bash
npm install
npm run dev       # שרת פיתוח (Vite)
npm test          # בדיקות יחידה (node:test)
npm run build     # בנייה ל-dist/
```

פרמטרים שימושיים בכתובת:

| פרמטר | משמעות |
|---|---|
| `?fresh` | פתיחה בלי לטעון את העבודה השמורה (לא מוחק אותה; השמירה הבאה תדרוס אותה) |
| `?t=0` | מצב אימות סטטי עבור `scripts/verify-content.mjs` |
